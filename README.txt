ПРАКТИЧЕСКАЯ РАБОТА № 4 — МОДУЛЬНОЕ ТЕСТИРОВАНИЕ
Проект: вычисление рядов Маклорена, C# / .NET 8 / Visual Studio

Состав:
- PR4_Maclaurin.sln — решение Visual Studio;
- MaclaurinConsole — консольное приложение;
- MaclaurinTests — MSTest-проект с позитивными и негативными тестами;
- Отчет_ПР4.docx — отчет с тест-кейсами и листингом.

Запуск:
1. Установить Visual Studio 2022 с workload «Разработка классических приложений .NET» (или .NET desktop development / .NET).
2. Открыть PR4_Maclaurin.sln.
3. Дождаться восстановления NuGet-пакетов.
4. Для тестов: Test -> Run All Tests (Тест -> Выполнить все тесты).
5. Для приложения: в обозревателе решений выбрать MaclaurinConsole как запускаемый проект и нажать Ctrl+F5.

Также можно открыть терминал в папке решения:
  dotnet test
  dotnet run --project MaclaurinConsole

Ряды:
1) e^x = sum(k=0..n) x^k/k!
2) a^x = sum(k=0..n) (x ln(a))^k/k!, a > 0
3) ln(1+x) = sum(k=1..n) (-1)^(k+1) x^k/k!, область -1 < x <= 1
4) ln((1+x)/(1-x)) = 2 sum(k=0..n) x^(2k+1)/(2k+1), область |x| < 1

Внимание: для рядов с ограниченной областью определения приложение сообщает об ошибке, если x вне области сходимости.
